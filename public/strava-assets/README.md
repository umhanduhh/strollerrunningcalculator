# Strava Brand Assets

Download the following official assets from Strava Developer Portal:
https://developers.strava.com/guidelines/

Required Assets:
1. Connect with Strava button (orange, 48px height)
   - Save as: connect-with-strava.svg
   - Save as: connect-with-strava@2x.png (96px height)

2. Powered by Strava logo (horizontal, orange)
   - Save as: powered-by-strava.svg
   - Save as: powered-by-strava@2x.png

3. Strava logo (for general use)
   - Save as: strava-logo.svg

Place all assets in this directory: /public/strava-assets/

Brand Guidelines Compliance:
- Never modify, alter, or animate these logos
- "Powered by Strava" must be visible on every page
- Use official "Connect with Strava" button only
- All activity data must include "View on Strava" links
- Orange color code: #FC5200
